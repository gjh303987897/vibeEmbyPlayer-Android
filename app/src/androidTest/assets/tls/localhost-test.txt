localhost-test.p12 is a public, synthetic JVM unit-test TLS keypair.
Alias: localhost. Password: fixture-only. Subject/SAN: localhost.
It has no access to any real server or user data and is not included in production APKs.
Generated with the JDK keytool, RSA 2048 / SHA256withRSA, PKCS12.
Used to verify HTTPS backup streaming, Digest retries, downgrade rejection and hostname checks.
