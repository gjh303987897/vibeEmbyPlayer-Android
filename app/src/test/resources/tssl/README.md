# Qt interop fixture

`tssl-backup-qt-fixture.zip` was generated by the real Qt CLI at commit
`35e9b5e` (`feat(tssl): add compressed backups with legacy restore support`),
using its miniz archive writer. It contains one synthetic TSSL v2 document
with root digest `41` repeated 32 times, an identifier of 4096 `A` characters,
and a synthetic key consisting of bytes 1 through 32. It contains no real media keys.

Generation used an isolated data directory, not the desktop user's store:

```text
vibePlayerQT.com --data-dir <isolated-source> --json tssl import input.tssl
vibePlayerQT.com --data-dir <isolated-source> --json tssl backup --target local --local-path <output> --format zip
```

The archive test checks extraction, document validity and exact byte preservation.
Other tests independently construct stored/Deflate ZIPs and exercise malformed inputs.
